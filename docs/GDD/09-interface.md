# 09 — Interface

> Statut : 📋 Prévu. Conçue d'abord pour le **téléphone**, puis adaptée au PC (D-009).

## 1. Principes

- Lisible sur un écran de 6 pouces : textes de 14 px minimum, boutons tactiles de 48 px minimum.
- Mise à l'échelle relative à la taille de l'écran, jamais en pixels fixes.
- Rien d'important dans les coins hauts (masqués par les boutons Roblox sur mobile).
- Interface de combat minimale : l'information passe d'abord par le monde (sons, lumières).

## 2. Interface en partie

| Élément | Position | Contenu |
|---|---|---|
| Santé et armure | Bas gauche | Deux barres |
| Munitions | Bas droite (près du bouton tir) | Chargeur / réserve |
| Capacités | Au-dessus du bouton tir | 2 icônes avec temps de recharge |
| **Boussole** | Haut centre | Direction, marqueurs, extractions, signatures ennemies |
| **Chrono de l'Éclat** | Sous la boussole | Phase actuelle, prochaine couronne d'effondrement |
| **Signature** | Près de la santé | Jauge 0 à 100 |
| Butin porté | Bouton sac | 12 emplacements |

Les alertes d'effondrement combinent un son, une vibration (mobile) et un bord d'écran orange.

## 3. Écrans du Refuge

| Écran | Contenu |
|---|---|
| **Charge** | Équipement emporté, avertissement clair : « Tout ceci sera perdu si tu meurs » |
| **Codex** | Capacités débloquées, niveaux, variantes |
| **Forge** | Recettes, matériaux nécessaires |
| **Coffre** | Stockage, revente |
| **Portail** | Choix de l'Éclat, escouade, file d'attente |

## 4. Fin de partie

- **Extraction réussie** : récapitulatif du butin, XP gagnée, progression de maîtrise.
- **Mort** : qui t'a tué, avec quoi, et ce qui a été perdu. Rappel de ce qui a été **gagné
  quand même** (XP, maîtrise) pour adoucir la perte totale.

## 5. Premier lancement

Un court Éclat d'entraînement scénarisé (5 min, sans perte) qui enseigne : déplacement,
tir, parade, relique, extraction. Puis arrivée au Refuge.
